# CRUD Operation Project

A web-based application developed using **Django** and **SQLite3** that performs complete **CRUD (Create, Read, Update, Delete)** operations for managing records efficiently. This project demonstrates database handling, dynamic form processing, and backend development using Django’s built-in ORM.

---

## 🚀 Features

* Create new records and store them in the database
* Read/View all stored records
* Update existing records dynamically
* Delete records from the database
* Dynamic form handling using Django Forms
* Database management using Django ORM
* Real-time data operations with seamless user interaction

## ⚙️ Installation Guide

### Clone Repository

```bash
git clone <your-github-repository-link>
```

### Create Virtual Environment

```bash
python -m venv env
```

### Activate Virtual Environment

**Windows**

```bash
env\Scripts\activate
```

**Mac/Linux**

```bash
source env/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Apply Migrations

```bash
python manage.py makemigrations
python manage.py migrate
```

### Run Development Server

```bash
python manage.py runserver
```
